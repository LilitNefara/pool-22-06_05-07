# EXAM_06_03. Matrix rotation
The russian version of the task can be found in the repository.

## Task
| Exam_06_03 ||
| ------ | ------- |
| Level: | 4. |
| Topics: | Matrices. |
| Directory for the solution: | src/ |
| Solution files: | main.c |
| Input data: | Standard input stream (stdin) |
| Output data: | Standart output stream (stdout) |

Напишите программу, которая поворачивает матрицу размера M x N на 90 градусов по часовой стрелке. Размер матрицы указывается в стандартном потоке ввода stdin в виде двух положительных чисел, за которыми следуют M * N целых чисел, описывающих матрицу по строкам. Результат работы программы должен быть выведен в стандартный поток вывода stdout в виде таблицы (после каждой строки итоговой матрицы должен быть перевод строки); элементы должны быть разделены пробелами, а перед переводом строки пробелов быть не должно. В конце ответа не должно быть перевода строки. Проверьте корректность введенных данных. В случае ошибки выведите «n/a».

## Examples

| Input | Output |
| ------ | ------ |
| 2 3<br>1 2 3<br>4 5 6 | 4 1<br>5 2<br>6 3|3 3<br>1 2 3<br>4 5 6<br>7 8 9<br> 7 4 1<br>8 5 2<br> 9 6 3 |

> **Attention:** Убедительно просим вас обратить внимание, что процедура тестирования вашей программы включает анализ стиля написания кода. Пожалуйста, загляните в папку «materials/». Также обязательно проверьте программу на наличие утечек памяти.
