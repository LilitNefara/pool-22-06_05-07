# EXAM_06_02. Swapping rows
The russian version of the task can be found in the repository.

## Task
| Exam_06_02 ||
| ------ | ------- |
| Level: | 4. |
| Topics: | Matrices. |
| Directory for the solution: | src/ |
| Solution files: | main.c |
| Input data: | Standard input stream (stdin) |
| Output data: | Standart output stream (stdout) |

Создайте программу, которая меняет местами строки, содержащие первые вхождения минимального и максимального элементов матрицы, в матрице размера M x N.  Размер матрицы указан в стандартном потоке ввода stdin в виде двух положительных чисел, за которыми следуют M * N целых чисел, описывающих матрицу построчно.  Результат обмена должен быть выведен в стандартный поток вывода stdout в виде таблицы (после каждой строки итоговой матрицы должен быть перевод строки); элементы должны быть разделены пробелами, а перед переводом строки пробелов быть не должно.  В конце ответа не должно быть перевода строки.  Проверьте корректность введенных данных.  В случае ошибки выведите «n/a».

## Examples

| Input | Output |
| ------ | ------ |
| 4 3<br>1 2 3<br>4 5 6<br>7 8 9<br>10 11 12 | 10 11 12<br>4 5 6<br>7 8 9<br>1 2 3 |

> **Attention:** Убедительно просим вас обратить внимание, что процедура тестирования вашей программы включает анализ стиля написания кода. Пожалуйста, загляните в папку «materials/». Также обязательно проверьте программу на наличие утечек памяти.
